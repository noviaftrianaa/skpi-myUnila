## SLIDE 8: FITUR UTAMA - PENJADWALAN OTOMATIS

### ⏰ **Scheduler: Otomasi Sinkronisasi Data**

**Masalah Lama:**
- Harus manual sync data setiap hari
- Sering lupa update data
- Butuh waktu lama untuk sinkronisasi

**Solusi Scheduler:**
- ✅ Sinkronisasi otomatis terjadwal
- ✅ Bisa diatur harian, mingguan, bulanan
- ✅ Notifikasi jika ada error
- ✅ Riwayat sinkronisasi tersimpan

**Contoh Jadwal:**
- Dosen: Setiap hari pukul 02.00 WIB
- Penelitian: Setiap Senin pukul 03.00 WIB
- Publikasi: Setiap hari Minggu pukul 01.00 WIB

## SLIDE 12: ARSITEKTUR SISTEM

### 🏗️ **Sistem Terintegrasi dengan 3 Layanan Utama**

```
┌─────────────────────────────────────────┐
│         KONG API GATEWAY                │
│    (Gerbang Keamanan & Routing)         │
└─────────────────────────────────────────┘
              ↓         ↓         ↓
    ┌─────────┴─────┬──────┴──────┬─────────┐
    │               │             │         │
┌───▼────┐    ┌────▼─────┐  ┌───▼──────┐  │
│ Auth   │    │Dashboard │  │ SISTER   │  │
│Service │    │ Service  │  │ Service  │  │
└────────┘    └──────────┘  └──────────┘  │
    │              │              │        │
    └──────────────┴──────────────┴────────┘
                   ↓
           ┌──────────────┐
           │  SQL Server  │
           │   Database   │
           └──────────────┘
```

**Penjelasan Sederhana:**
- **Auth Service**: Menangani login & keamanan
- **Dashboard Service**: Menyajikan data & statistik
- **SISTER Service**: Sinkronisasi dengan Kemdikbud
- **Kong Gateway**: Mengatur akses & keamanan

## SLIDE 14: KEAMANAN SISTEM

### 🔒 **Keamanan Berlapis**

**Level 1: Authentication (Siapa Anda?)**
- Login dengan Username/Password
- SSO Unila (Single Sign-On)
- Multi-Factor Authentication (MFA/2FA)

**Level 2: Authorization (Apa Hak Anda?)**
- Role-based Access Control
- Admin, Developer, Public

**Level 3: Data Protection**

**Level 4: Infrastructure Security**
- Kong Gateway sebagai firewall

- Backup otomatis

## SLIDE 23: FAQ (Frequently Asked Questions)

### ❓ **Pertanyaan yang Sering Diajukan**

**Q: Apakah data aman?**
A: Ya, sistem menggunakan enkripsi dan multi-layer security. Data backup otomatis setiap hari.

**Q: Bagaimana jika SISTER berubah?**
A: Sistem dirancang modular, mudah di-update jika SISTER API berubah.

**Q: Apakah bisa akses dari mobile?**
A: Ya, website responsive dan mobile app dalam pengembangan (Fase 2).

**Q: Siapa yang bisa akses sistem?**
A: Publik bisa lihat info umum. Admin/Developer bisa kelola data dengan login.

**Q: Bagaimana jika ada error saat sync?**
A: Sistem akan retry otomatis 3x dan mengirim notifikasi jika gagal.

**Q: Berapa lama training untuk admin?**
A: Sekitar 2-3 hari untuk menguasai semua fitur admin.
