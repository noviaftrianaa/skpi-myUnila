4. Daftar Endpoint

Bagian ini mendokumentasikan endpoint per grup. Untuk batch review pertama disertakan: Auth (2 endpoint) dan sample Referensi (8 endpoint). Batch berikutnya akan menambahkan modul lain secara bertahap.

4.1 Grup Auth

POST /v1/auth/login
Otentikasi pengguna & terbitkan JWT access token

Memvalidasi kombinasi id_aplikasi + username + password terhadap sistem manajemen akses. Pengguna wajib berstatus aktif dan memiliki peran Developer (id_peran = 107) di organisasi Universitas Lampung. Kalau valid, server menerbitkan JWT yang berlaku 1 jam.

Request body
FieldTipeWajibKeterangan
id_aplikasistring (UUID)YaUUID aplikasi konsumen
usernamestringYaUsername PJ Aplikasi
passwordstringYaPassword PJ Aplikasi (plain, di-hash di server)
Contoh request
POST /v1/auth/login HTTP/1.1
Host: my.unila.ac.id
Content-Type: application/json

{
  "id_aplikasi": "00000000-1111-2222-3333-444444444444",
  "username": "app_pj",
  "password": "RahasiaKuat!2026"
}

POST /v1/auth/check-token
Verifikasi token JWT (status, identitas pemilik)

Memvalidasi tanda tangan, masa berlaku, dan keberadaan claim jti token JWT. Berguna untuk konsumen yang ingin memastikan token masih sah sebelum dipakai pada batch request panjang, atau untuk mendapatkan info pengguna pemilik token tanpa parsing manual JWT.

Request body
FieldTipeWajibKeterangan
token_bearerstring (JWT)YaNilai token tanpa prefix "Bearer "
Contoh request
POST /v1/auth/check-token HTTP/1.1
Content-Type: application/json

{
  "token_bearer": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."
}
