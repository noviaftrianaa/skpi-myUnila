4.2 Grup Referensi (sample 8 endpoint)

Endpoint referensi menyediakan master data yang umum dipakai sebagai dropdown / lookup di aplikasi konsumen. Semua endpoint mendukung pagination standar (page, limit) dan dapat di-cache di sisi konsumen karena data jarang berubah.

GET /v1/referensi
Indeks daftar sub-endpoint referensi

Mengembalikan ringkasan semua sub-endpoint referensi yang tersedia. Berguna untuk self-discovery / introspeksi.

Query parameter

Tidak ada (endpoint statis).

Response 200 (cuplikan)
{
  "success": true,
  "message": "Daftar referensi",
  "data": [
    { "kode": "agama",              "url": "/v1/referensi/agama" },
    { "kode": "jenjang_pendidikan", "url": "/v1/referensi/jenjang_pendidikan" },
    { "kode": "jurusan",            "url": "/v1/referensi/jurusan" },
    ...
  ],
  "timestamp": "2026-04-25T15:00:00+07:00"
}

GET /v1/referensi/wilayah
Daftar wilayah administrasi (provinsi/kota/kabupaten/kecamatan)
Query parameter
ParamTipeDefaultKeterangan
pageint1Halaman
limitint20Maks 100
searchstring-Cari di nm_wil
id_level_wilint-1=Provinsi, 2=Kota, 3=Kecamatan
id_induk_wilstring-Kode wilayah induk (untuk drill-down)
Response 200 (cuplikan)
{
  "data": [
    { "id_wil": "180000", "nm_wil": "Prov. Lampung",     "id_level_wil": 1, "id_induk_wil": "000000" },
    { "id_wil": "187100", "nm_wil": "Kota Bandar Lampung","id_level_wil": 2, "id_induk_wil": "180000" },
    { "id_wil": "187171", "nm_wil": "Kec. Kedaton",       "id_level_wil": 3, "id_induk_wil": "187100" }
  ],
  "meta": { "page": 1, "limit": 20, "total": 87412, "total_pages": 4371 }
}
Tip: wilayah punya banyak baris (87k+). Gunakan id_level_wil + id_induk_wil untuk drill-down (provinsi → kota → kecamatan), bukan fetch all di awal.
