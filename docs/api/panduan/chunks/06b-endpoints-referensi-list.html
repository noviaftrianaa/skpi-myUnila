4.3 Grup Referensi — Daftar Lengkap

Selain 8 endpoint sample yang sudah didokumentasikan dengan detail di sub-bab sebelumnya, Web Service myUnila menyediakan total 93 endpoint referensi GET. Sebagian besar mengikuti pola request/response yang serupa, jadi cukup pahami pola umum kemudian panggil endpoint sesuai kebutuhan.

Pola Standar Endpoint Referensi

Semua endpoint referensi GET mengikuti pola berikut:

GET /v1/referensi/{kode}?page=1&limit=20&search=<kata>
Authorization: Bearer <jwt>
ParamTipeDefaultKeterangan
pageint1Halaman ke-N
limitint20Maks 100 per halaman
searchstring-LIKE-search di kolom nama utama (case-insensitive)
sort_bystringvariesKolom sort (umumnya kolom nm_* atau ID)
sort_orderstringascasc | desc

Format response:

{
  "success": true,
  "message": "Berhasil mengambil data {kode}",
  "data": [ /* array of objects */ ],
  "meta": { "page": 1, "limit": 20, "total": N, "total_pages": M },
  "timestamp": "2026-04-25T15:00:00+07:00"
}
Tip caching: data referensi jarang berubah. Konsumen disarankan cache result minimum 6-24 jam supaya tidak boros rate-limit. Pakai HTTP cache key {kode}+limit+page.
